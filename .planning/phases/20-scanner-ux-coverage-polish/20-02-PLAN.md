Scanner trigger conditions (from research + source analysis):
| Scanner | pattern_type | Trigger |
|---------|-------------|---------|
| redundancy | scan_redundancy | Same heading text in CLAUDE.md and a rule file |
| mechanization | scan_missing_mechanization | Rule text matching MECHANIZATION_INDICATORS regex AND no hook registered for that event |
| staleness | scan_stale_reference | `@docs/missing.md` reference to non-existent file in CLAUDE.md |
| conflict | scan_rule_conflict | "always use X" in CLAUDE.md + "never use X" in rule file (opposition pair regex) |
| structure | scan_structure_issue | Empty rule file (0 bytes) |
| hooks-redundancy | scan_hooks_redundancy | Duplicate hook entries (same event, same command) in settings.json |
| commands | scan_command_convention | Empty command file in .claude/commands/ |

Conflict scanner opposition pair regex (CRITICAL — must match exactly):
```typescript
/\b(?:always|must)\s+(?:(?:use|allow|always)\s+)*(\S+)/i  // "always use TypeScript"
/\b(?:never|must\s+not|do\s+not)\s+(?:(?:use|allow|always)\s+)*(\S+)/i  // "never use TypeScript"
```
The subject capture group must match between the two patterns. "TypeScript" vs "TypeScript" works.

Mechanization scanner trigger regex (CRITICAL — must match):
```typescript
/always\s+run\s+["`']?(\S+)/i  // "always run lint"
/before\s+committing?,?\s+run\s+["`']?(\S+)/i  // "before committing, run lint"
```
AND hooks_registered must NOT contain a hook with matching event type (PreToolUse).
