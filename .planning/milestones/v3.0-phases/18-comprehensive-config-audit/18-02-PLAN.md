    **Checks (in order):**

    1. **Exact duplicate hooks:** Two or more entries with the same `event` + same `scope` + same `command` string. Build a Map keyed by `${event}|${scope}|${command ?? ''}`. If any key has 2+ entries, it's a duplicate.
       - `severity`: `'problem'`
       - `confidence`: `'HIGH'`
       - `target`: `'SETTINGS'`
       - `suggested_action`: `"Remove duplicate hook registration for ${event} in ${scope} settings.json. Both entries run '${command}'. Expected effect: eliminates double-execution of the same hook script."`

    2. **Hooks without commands:** Entries where `type === 'command'` but `command` is undefined or empty string. These hooks will fail silently when triggered.
       - `severity`: `'problem'`
       - `confidence`: `'HIGH'`
       - `target`: `'SETTINGS'`
       - `suggested_action`: `"Add a command to the ${event} hook in ${scope} settings.json, or remove the empty hook entry. Expected effect: hook will actually execute instead of failing silently."`

    3. **Same command across scopes:** Two entries with the same `command` string but different `scope` (e.g., user + project). This causes the command to run twice.
       - Build a Map keyed by `${event}|${command}`, collecting all scopes. If any key spans 2+ scopes, flag it.
       - Skip entries where command is undefined.
       - `severity`: `'suggestion'`
       - `confidence`: `'MEDIUM'`
       - `target`: `'SETTINGS'`
       - `suggested_action`: `"Hook command '${command}' for ${event} is registered in both ${scopeA} and ${scopeB} scope. This causes double-execution. Keep it in one scope only. Expected effect: hook runs once instead of twice per trigger."`

    **Helper function -- extract frontmatter from command content:**
    ```typescript
    function extractCommandFrontmatter(content: string): Record<string, string> | null {
      const match = content.match(/^---\n([\s\S]*?)\n---/);
      if (!match) return null;
      const fields: Record<string, string> = {};
      for (const line of match[1].split('\n')) {
        const kvMatch = line.match(/^(\w[\w-]*):\s*(.+)$/);
        if (kvMatch) fields[kvMatch[1]] = kvMatch[2].trim();
      }
      return fields;
    }
    ```

    **Helper function -- content after frontmatter:**
    ```typescript
    function contentAfterFrontmatter(content: string): string {
      const match = content.match(/^---\n[\s\S]*?\n---\n?([\s\S]*)$/);
      return match ? match[1].trim() : content.trim();
    }
    ```

    **Checks (in order):**

    1. **Empty command file:** `content.trim().length === 0`.
       - `severity`: `'problem'`
