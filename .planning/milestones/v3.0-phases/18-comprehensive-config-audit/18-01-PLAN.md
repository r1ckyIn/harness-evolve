    The scanner detects contradictory directives between CLAUDE.md files and rule files by finding opposing keyword pairs that reference the same subject.

    **Algorithm:**
    1. Define opposition pairs as an exported constant `OPPOSITION_PAIRS`:
       ```typescript
       export const OPPOSITION_PAIRS: Array<[RegExp, RegExp, string]> = [
         [/\b(?:always|must)\s+(?:use\s+)?(\S+)/i, /\b(?:never|must\s+not|do\s+not)\s+(?:use\s+)?(\S+)/i, 'always vs. never'],
         [/\benable\s+(\S+)/i, /\bdisable\s+(\S+)/i, 'enable vs. disable'],
       ```

       - `evidence`: `{ count: 2, examples: [sourceA path, sourceB path] }`
       - `suggested_action`: Must include concrete action AND expected effect. Format: `"Resolve the contradiction between ${pathA} and ${pathB}. Either remove the directive from one source or align them. Expected effect: Claude will follow a single, unambiguous instruction instead of choosing between conflicting ones."`

    The scanner audits `.claude/rules/` directory for structural quality issues.

    **Checks (in order):**

    1. **Empty/near-empty rules:** For each rule in `context.rules`, check if `content.trim().length < 10`. These are likely placeholders or mistakes.
       - `severity`: `'problem'`
       - `confidence`: `'HIGH'`
       - `suggested_action`: `"Remove the empty rule file at ${path} or add meaningful content. Expected effect: reduces Claude's context loading overhead and eliminates confusion from placeholder files."`

    2. **Oversized rules (>200 lines):** Check `content.split('\\n').length > 200`.
       - `severity`: `'suggestion'`
       - `confidence`: `'MEDIUM'`

    3. **Rules without headings:** Check `headings.length === 0` AND `content.trim().length >= 10` (skip empty rules already flagged).
       - `severity`: `'suggestion'`
       - `confidence`: `'LOW'`
       - `suggested_action`: `"Add markdown headings to ${filename} to improve organization. Expected effect: Claude can parse and reference specific sections more accurately."`

    4. **Rules in subdirectory without paths frontmatter:** Check if rule path contains more than one directory level under `.claude/rules/` (i.e., the path after `.claude/rules/` contains a `/`), AND `frontmatter` is undefined or `frontmatter.paths` is undefined/empty.        - `suggested_action`: `"Add a paths: frontmatter to ${filename} to scope it to specific files. Expected effect: rule only loads when editing matching files, reducing irrelevant context."`

    **Detection for "in subdirectory":** Extract the relative path after `.claude/rules/` by finding the index of `.claude/rules/` in the rule's path string. If the remaining path after that contains a `/` separator (e.g., `01-workflow/dev.md`), it's in a subdirectory.
